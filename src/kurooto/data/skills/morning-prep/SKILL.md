Draft today's plan. Extra context: $ARGUMENTS

This usually runs unattended before they wake up: don't ask anything now; write a draft and list what you'd ask
them.

**Read:**
- their term note in `terms/` (timetable, key dates) and its study plan, if there is one;
- each subject's course page `<subject>/course` (`## Tasks`, `## Exams`) and `<subject>/exam-prep`;
- notes in `research/` they're working on (their `## Log`);
- yesterday's daily note (journal, plan, what didn't get done) and today's (`## From last night`);
- what needs attention now, with the tools you have (pending_items, the deadline tools, today's classes);
- `about-me/how-to-help-me`: how they like to be helped. Follow it.

**Write** in today's daily note `journal/<today>` (create it with the first line `# YYYY-MM-DD` if it's missing) a
section `## Plan for today (draft, HH:MM)`:
- **Classes today:** each with a link to its course page and the last lecture note, plus what to look at before
  class (one line).
- **Due soon:** deadlines in the next 7 days, soonest first, with dates; tests and exams within 14 days stand out.
- **Time to start:** if you have the start_by tool, what it says to start now (start-by dates, an estimate), with
  the size it gives; put the first step of each into the Top 3 or the blocks.
- **Top 3:** the three things that matter most today, each with a one-line reason (an exam soon, a deadline, what
  slipped yesterday).
- **Suggested blocks:** a rough time-blocked day around the classes: study, practice, project work, breaks.
- **Questions for the morning:** the 3 to 5 things only they can answer that would change this plan. Always ask
  which classes they're skipping today, and when they'd like the check-in call.

If you have the plan_block tool, put each suggested block (not the classes) in their calendar with it.

Reply in two lines: the Top 3, and that the draft is in today's daily note.
