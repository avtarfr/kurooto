Repository layout

One line per folder or important file. Paths are relative to the repository root.

Top level

PathWhat it is
README.mdthe public front page: what Kurooto does, install, first steps, links to docs
AGENTS.mda guide for AI agents helping a user install, set up and fix Kurooto (not for developing it; that's agents.md)
CHANGELOG.mduser-facing changes per version, newest first, (unreleased) for work in progress
LICENSE, NOTICEApache-2.0
pyproject.tomlpackage metadata and the version, dependencies, the kurooto entry point (kurooto.cli:main), ruff and pytest config, hatch build (the APK as an artifact)
uv.lockthe locked development environment (uv sync --locked)
requirements.lockhashed runtime requirements used by installs and updates (--require-hashes); must match uv export
.github/workflows/CI: ci.yml (tests, call line, Android, privacy, update rehearsal), android-emulator.yml, spike-agy.yml, spike-gbrain.yml
.gitleaks.toml, .gitleaksignoregitleaks configuration for the privacy job and hook
.gitignorebuild output, venvs, node_modules, .wrangler, keys, .env*, the bundled public/app.js, wrangler.toml, the APK
src/kurooto/the Python package (below)
tests/pytest suite, fakes, JS tests, fixtures (below)
addons/add-ons ready to publish as repositories of their own (restic-backups, desktop-helpers, habits, handwriting-pull, night-performance), each with kurooto-addon.json, a README and tests; conftest.py adds one by link in tests (in testpaths)
tools/release, privacy scanner, settings guide generator, update rehearsal, git hooks (below)
installer/install.sh, install.ps1, bootstrap.py (verifies signed releases, builds the first version), index.html and privacy.html templates for the site
android/the Android app (below)
docs/user and maintainer documentation (below)

src/kurooto/

PathWhat it is
__init__.py__version__ from the installed metadata
__main__.pypython -m kurooto → cli.main
cli.pyevery kurooto subcommand (argparse in main()); talks to the daemon through the local API (ask_running)
daemon.pyrun() (the daemon), serve(), supervise(), logging setup, single-instance lock
app.pyApp: builds the core services and modules, handle() routes messages, callback() routes buttons, enable/disable
diagnostics.pykurooto doctor rows and the redacted diagnostics zip
top.pykurooto top, the terminal status board
watch.pykurooto watch -- CMD and the log follower for kurooto logs -f
runlog.pykurooto runlog, experiment-run logs written into the notes
runcompare.pyrun compare (the Research add-on): kurooto runlog diff and /runs compare
popup.pykurooto ask --popup, the Quick ask window (Tk); Asker is its logic, testable without a window
core/shared services: settings, secrets, paths, scheduler, jobs, events, notify, Calm, ask, availability, power, presence, quota, health, tools, MCP, places, layout, the concept graph's engine, ... (core.md)
providers/AI brains: base.py (interface), agy.py, claude.py, openai_compat.py, effort.py, context.py, registry in __init__.py (brains.md)
modules/one file (or package) per feature, base.py (the Module class), catalog.py (the list) (modules.md)
modules/telegram/the Telegram channel and a stdlib Bot API client (api.py)
modules/calls/phone calls: connector, deploy, fallback, crypto (line.py), phone app channel, post-call review (calls-and-phone.md)
modules/terminal/Kurooto Terminal (kitty, Windows Terminal, launchers, default terminal)
modules/curious.pynot a feature: Dreaming's curious and resurfacing lines (rules only) and their buttons
modules/latex_tracker.pynot a feature: the Research add-on's LaTeX tracker (build, log, words, BibTeX)
modules/consolidate.pynot a feature: Dreaming's "Worth a look in what I remember" (duplicates and lines that disagree) and its buttons
modules/fold.pynot a feature: Dreaming's "For your profile" (lasting things you said, Keep / Not that / Undo into your profile or how-to-help-me note)
modules/coursepages.pynot a feature: the notes brain's course pages (key concepts and a dated timeline per course)
modules/photodates.pynot a feature: Photo to dates, part of Deadlines (a photo's dates read by the AI, offered through core/dateoffers.py)
modules/mailin.pynot a feature: Email in, part of Mail digest (mail to +kurooto or a label, filed into notes)
web/the local HTTP server, API, live events, tools API, try-it; web/static/ the pages and scripts (web.md)
update/launcher.py (stdlib-only, copied into the app folder), updater.py, service.py, signing.py (release-and-updates.md)
data/package data: skills/<name>/SKILL.md (shipped skills), prompts/, prereqs.toml (helper programs and their checksums), ollama_models.toml (models per hardware profile), research_sources.json, troubleshooting.md (a copy of the user wiki's, for /fixme), known_issues.json (/fixme's known issues, signed with the release), worker/ (the call line's Worker source)
data/worker/src/worker.js, web/app.js + web/fallback.js (call page source), public/ (static pages, service worker), package.json + package-lock.json, wrangler.template.toml

tests/

PathWhat it is
conftest.pythe env fixture (a paired app with a fake Telegram), autouse isolation fixtures, the guard's pytest hooks
isolation.pythe real-install guard: pretend home, stand-in programs, audit hook (testing.md)
unit/about a hundred test files, roughly one per feature or core service
integration/the call line under wrangler dev with fakes (needs Node and the Worker's packages)
fakes/Telegram, OpenAI-style APIs, Ollama, agy, Claude Code, an MCP agent, Google, the cloud services the Worker uses
js/Node tests for the call page, its fallback logic and the Worker's crypto
fixtures/call-vectors.json (crypto vectors shared by Python, the Worker and Java), syscolors/

tools/

PathWhat it is
release.pykeygen, build, sign, yank, publish (release-and-updates.md)
privacy_scan.py, privacy_allow.txtthe scanner for secrets and personal data, and the paths exempt from its pattern layer
gen_settings_guide.pywrites docs/SETTINGS_GUIDE.md from the code (--check for CI and tests)
update_rehearsal.pyinstalls, updates, rolls back and uninstalls with the real installer in a sandbox
hooks/pre-commit, hooks/pre-pushprivacy scan and noreply identity checks (git config core.hooksPath tools/hooks)

PathWhat it is

res/, assets/isrgrootx1.dericons; the Let's Encrypt root for old Android versions

settings.gradle.kts, build.gradle.kts, gradle.properties, proguard-rules.prothe Gradle build (versions pinned in build.gradle.kts)
smoke.shemulator smoke test
test/CryptoTest.java (shared vectors), SpeechTest.java

docs/

PathWhat it is

media/screenshots and video for the README and site (left out of release builds)
